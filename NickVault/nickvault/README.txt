# NICKVAULT – Nickelodeon Digital Archive

## ABOUT THE PROJECT

NickVault is a digital archive and discovery platform dedicated to Nickelodeon television shows and cartoons, both classic and modern.

It allows users to explore different shows, view their posters, discover their creators and producers, learn about their release years, and read interesting facts and descriptions.

The project aims to bring Nickelodeon's entertainment history together in one interactive and user-friendly website.

## PROJECT FILES

- `index.html` – Main page structure.
- `style.css` – Responsive website styling.
- `script.js` – Show information, search, filters, random facts, popups and poster image URLs.

## HOW TO RUN

1. Extract the ZIP into a folder.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server (or open it in a browser).
4. Keep an internet connection active because poster images are loaded from external image sources.

## POSTER IMAGE SOURCES

The poster image URLs point to third-party image sources. These are listed in the original project documentation.

## IMPORTANT

NickVault is an educational, fan-made project. Nickelodeon characters, shows and related images remain the property of their respective copyright owners.

Some external image links may stop working or become unavailable. Local image files can be stored in `assets/posters` and referenced in `script.js` when necessary.
